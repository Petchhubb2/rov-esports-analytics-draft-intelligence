# 13 — คู่มือใช้ Draft Simulator

ใช้งานได้แล้ววันนี้ ไม่ต้องรอกรอก hero attribute
เพราะคำแนะนำทั้งหมดมาจาก **ข้อมูลแมตช์จริง 861 เกม**

---

## 1. เริ่มใช้

```bash
rov draft sim --blue SLX --red DCG
```

ตัวเลือกอื่น

```bash
rov draft sim --region TH        # ใช้ข้อมูลเฉพาะลีกไทย
rov draft sim --region TW        # ใช้ข้อมูลเฉพาะลีกไต้หวัน
rov draft sim --top 12           # แสดงคำแนะนำ 12 อันดับ
rov draft sim --min-games 15     # แนะนำเฉพาะฮีโร่ที่มีข้อมูลพอ
```

```

  #  hero                รวม   meta     wr    ctr    syn   เกม
  1  rouie              76.3    100     88     50     50   195
  2  sinestrea          73.5     93     86     50     50   162
  3  marja              69.6     82     84     50     50   286

  อันดับ 1 · rouie
    · อยู่ในเมตาหนัก presence 88%
    · ถูกแบนมากกว่าถูกเลือก 565 ต่อ 195 — ทีมอาชีพกลัวตัวนี้
    Meta         100  pick 195 ban 565 จาก 861 เกม
    Win rate      88  0.560 จาก 195 เกม (ถ่วงตัวอย่างแล้ว)
    Counter       50  ศัตรูยังไม่ได้เลือก จึงยังคิด counter ไม่ได้
    Synergy       50  ทีมยังไม่ได้เลือก จึงยังคิด synergy ไม่ได้
```

### องค์ประกอบทั้งสี่

| ชื่อ | น้ำหนัก | ความหมาย | ที่มา |
|------|--------|----------|-------|
| `meta` | 0.30 | ทีมอาชีพให้ค่าฮีโร่นี้แค่ไหน | pick + ban จาก 861 เกม |
| `wr` | 0.30 | อัตราชนะ ถ่วงด้วยขนาดตัวอย่างแล้ว | Beta shrinkage k=30 |
| `ctr` | 0.25 | ได้เปรียบตัวที่ศัตรูเลือกไปแล้วแค่ไหน | matchup 6,037 คู่ |
| `syn` | 0.15 | เข้ากับตัวที่ทีมเราเลือกไปแล้วแค่ไหน | synergy คู่ในทีม |

**ค่า 50 แปลว่าเป็นกลาง** ไม่ใช่ว่าดีปานกลาง
ช่วงต้น draft counter กับ synergy จะเป็น 50 หมด เพราะยังไม่มีใครเลือกอะไร
ตัวเลขจะเริ่มมีความหมายตั้งแต่ตาที่ 5 เป็นต้นไป

**ดาว `*` ท้ายบรรทัด** แปลว่าฮีโร่นั้นเล่นน้อยกว่า 15 เกม ตัวเลขยังไม่นิ่ง

### ตอนแบน ระบบมองจากมุมศัตรู

เพราะการแบนคือการตัดตัวเลือกของอีกฝ่าย ระบบจึงคำนวณว่า
ฮีโร่ตัวไหน **ดีต่อศัตรู** มากที่สุด แล้วแนะนำให้แบนตัวนั้น
รวมถึงดู synergy กับสิ่งที่ศัตรูเลือกไปแล้วด้วย

และจะไม่แนะนำให้แบนตัวที่ศัตรูใช้ไม่ได้อยู่แล้วเพราะ Global Ban-Pick
ซึ่งเป็นการเสียตาแบนเปล่า ๆ

## 4. กติกาที่ระบบบังคับให้

| กติกา | สถานะ |
|-------|-------|
| ฮีโร่ที่ถูกเลือกหรือแบนแล้ว หยิบซ้ำไม่ได้ | ✅ |
| แบน 4 เลือก 5 ต่อทีม | ✅ ยืนยันจากข้อมูล 861 เกม |
| Global Ban-Pick — ห้ามใช้ตัวที่ทีมตัวเองเคยเลือกในซีรีส์ | ✅ ยืนยันแล้ว |
| หยิบตัวที่ฝ่ายตรงข้ามเคยใช้ได้ (soft fearless) | ✅ |
| แบนตัวที่ตัวเองเคยใช้ได้ | ✅ |
| Bo7 เกมสุดท้ายรีเซ็ตกติกา | ✅ |

### ใช้ Global Ban-Pick กับซีรีส์จริง

**บนหน้าเว็บทำได้ครบแล้ว ไม่ต้องเขียนโค้ด** — ดู §5

ถ้าจะเรียกจากโค้ดโดยตรง

```python
from rov.domain.enums import Team
from rov.draft.state import DraftFormat, DraftState

st = DraftState(
    fmt=DraftFormat.load(),
    pool=pool_of_heroes,
    series_used={
        Team.BLUE: {"rouie", "marja"},   # SLX ใช้ไปแล้วในเกม 1-2
        Team.RED: {"sinestrea"},
    },
    is_final_game=False,
)
```

## 5. ซีรีส์ Bo1 / Bo3 / Bo5 / Bo7 บนหน้าเว็บ

แถบ **SERIES** ใต้กระดานคุมทั้งซีรีส์

| ส่วน | ทำอะไร |
|------|--------|
| ปุ่ม Bo1 / Bo3 / Bo5 / Bo7 | เลือกรูปแบบ ระบบคิดเองว่าต้องชนะกี่เกม (⌈n/2⌉) |
| สกอร์ `2 – 1` | ยอดเกมที่แต่ละฝั่งชนะ |
| จุดกลม 1..n | ผลรายเกม สีน้ำเงิน/แดงคือผู้ชนะ ขอบเหลืองคือเกมที่กำลังดราฟต์ |
| ปุ่ม *ฝั่งน้ำเงิน / ฝั่งแดง* | บันทึกว่าใครชนะเกมนี้ แล้วขึ้นเกมถัดไปให้เลย |
| ↩ ผลเกมล่าสุด | ย้อนผลเกมที่เพิ่งบันทึก |
| ล้างซีรีส์ | เริ่มนับใหม่ทั้งหมด |

**ปุ่มบันทึกผลจะกดไม่ได้จนกว่าจะดราฟต์ครบทั้ง 18 ตา** เพราะกติกา
Global Ban-Pick ต้องรู้ว่าเกมนั้นแต่ละทีมเลือกอะไรไปบ้าง ถ้าดราฟต์ไม่ครบ
เกมถัดไปจะล็อกตัวผิด

### ตัวที่เล่นไปแล้วจะหยิบซ้ำไม่ได้

พอบันทึกผลเกม ตัวที่ทีมนั้น **เลือก** (ไม่ใช่แบน) จะถูกล็อกในเกมถัดไป
บนกระดานจะเห็นเป็นการ์ดสีจาง กดไม่ได้ พร้อมป้าย *ใช้แล้วในซีรีส์*
และแถว Global Ban-Pick ด้านล่างจะไล่ชื่อตัวที่ใช้ไปแล้วของทั้งสองฝั่ง

ล็อกเฉพาะฝั่งตัวเอง — ตัวที่ **คู่แข่ง** ใช้ไปแล้วเรายังหยิบได้ (soft fearless)
และการ **แบน** ไม่ถูกจำกัด จะแบนตัวที่ตัวเองเคยเล่นก็ได้

พอถึงเกมตัดสิน (เกมที่ n ของ Bo-n) ล็อกทั้งหมดจะถูกปลด กลับเป็น
Normal Ban-Pick ตามที่ `configs/draft/format.yaml` ตั้ง `reset_on_final_game: true`
ตอนนั้นแถบซีรีส์จะขึ้นว่า *เกมตัดสิน กลับเป็น Normal Ban-Pick*

> ⚠️ กติกาการรีเซ็ตนี้ยืนยันมาจากรูปแบบ Bo7 การเอาไปใช้กับเกมสุดท้ายของ
> Bo3/Bo5 เป็นการตีความของเราเอง ถ้ารายการที่คุณดูไม่ได้ใช้กติกานี้
> ให้ตั้ง `reset_on_final_game: false` แล้วรัน `build_draft_page.py` ใหม่

### กดสลับฝั่งกลางซีรีส์

ปุ่ม *สลับฝั่ง* ย้ายทั้งชื่อทีม ประวัติผลเกม และตัวที่ล็อกไว้ตามไปด้วย
ใช้ตอนที่ทีมสลับข้างในเกมถัดไป ซึ่งเกิดทุกซีรีส์จริง

## 6. หน้า "ตัวแก้ / แพ้ทาง"

แท็บที่สองด้านบน เปิดดูได้ทุกเมื่อ ไม่ต้องอยู่กลางดราฟต์

เลือกฮีโร่จากรายชื่อซ้ายมือ (เรียงตาม presence) แล้วจะเห็นสองคอลัมน์

* **▲ เจอแล้วได้เปรียบ** — ตัวที่เจอแล้วอัตราชนะสูงกว่าปกติ
* **▼ เจอแล้วเสียเปรียบ** — ตัวที่เจอแล้วแย่ลง

แต่ละแถวบอก `ชนะ-แพ้ · %` ดิบ แถบเทียบขนาด และคะแนนถ่วงน้ำหนัก
สไลเดอร์ *เกมขั้นต่ำ* กรองคู่ที่ข้อมูลน้อยออก เริ่มที่ 8 เกมซึ่งเป็นเกณฑ์
ต่ำสุดที่ export ไว้ (`MIN_PAIR_GAMES`)

### อ่านตัวเลขยังไง

เป็นคะแนนตัวเดียวกับช่อง `counter` ในหน้าดราฟต์

```
(อัตราชนะถ่วง Beta k=30 − 50%) × 100 × ความมั่นใจ
ความมั่นใจ = เกมที่เจอกัน / (เกมที่เจอกัน + 30)
```

คู่ที่เจอกันไม่กี่เกมจึงถูกดึงเข้าหา 0 เอง ไม่พุ่งไปสุดขอบ
**ผลคือค่าจริงจากข้อมูล 861 เกมอยู่ราว ±5 ไม่ใช่ ±50** ให้ดูลำดับกับ
แถบเทียบกัน อย่าไปตีความตัวเลขดิบว่าน้อย

ช่อง `ชนะ-แพ้ · %` เป็นสถิติดิบไม่ถ่วงน้ำหนัก ใส่ไว้ให้เห็นว่าคะแนนมาจากไหน
คู่ที่ % ดิบสวยมากแต่คะแนนต่ำ แปลว่าเจอกันน้อยเกินจะเชื่อ

> ⚠️ **ยังเป็น context=TEAM** เหมือนเดิม — นับจากการอยู่คนละทีมในเกมเดียวกัน
> ไม่ได้แปลว่าประกบกันในเลน ตัวที่ขึ้นว่า "แพ้ทาง" อาจไม่เคยเจอหน้ากันเลยก็ได้
> ดู §5 เดิม (ตอนนี้เป็น §7) ประกอบ

## 7. ⚠️ สิ่งที่ต้องรู้ก่อนเชื่อ

### ลำดับ ban/pick ยังไม่ได้ยืนยัน

ข้อมูลยืนยันแค่ว่า **แบน 4 เลือก 5 ต่อทีม** แต่ Liquipedia ไม่ได้เก็บ
ลำดับการสลับกันระหว่างสองทีม และหา rulebook ทางการไม่พบ

ลำดับที่ใช้อยู่เป็นรูปแบบมาตรฐานของ MOBA ทั่วไป
ถ้าดูคลิปแข่งแล้วพบว่าต่าง **แก้ที่ `configs/draft/format.yaml` ไฟล์เดียว**
ไม่ต้องแก้โค้ด แล้วเปลี่ยน `verified: true`

### ยังไม่ได้คิดเรื่องเหล่านี้

| ขาดอะไร | ต้องรออะไร |
|---------|-----------|
| Composition (role balance, damage mix, engage/peel) | กรอก hero attribute |
| ความถนัดของผู้เล่นแต่ละคน | player stats จาก vision |
| Counter แยกตามเลน | role assignment จาก vision |
| สภาพเลนและ power spike | vision pipeline |

จึงต้องเรียกผลนี้ว่า **คำแนะนำจากสถิติ** ไม่ใช่ "ตัวที่ดีที่สุด"

### ข้อมูลยังรวมข้าม patch

ขัดกฎข้อ 5 ของ Blueprint ตรง ๆ ต้องแก้ต่อ
ตอนนี้จึงเหมาะกับการดูแนวโน้มกว้าง ๆ มากกว่าการตัดสินใจละเอียด

### counter ยังเป็น context=TEAM

หมายถึงอยู่คนละทีมในเกมเดียวกัน ไม่ได้แปลว่าดวลกันในเลนเดียวกัน

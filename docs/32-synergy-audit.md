## 1. synergy ตอนนี้มาจากไหน

มีสอง component ทั้งคู่อยู่ใน [`recommend.py`](../packages/core/rov/draft/recommend.py)

| component | น้ำหนัก | ตัวเทียบ | สถานะ |
|---|---|---|---|
| `synergy` | **0.05 → 0.28** | `prior` (0.5) | ✅ ทำงาน · มีน้ำหนักจริง |
| `synergy_adj` | **0.0** | `expected_synergy()` | ✅ ทำงาน · ปิดอยู่ตั้งแต่ PHASE B |

ทั้งคู่ใช้สูตรเดียวกัน (`stats.counter_score`) **ต่างกันที่ตัวเทียบ ไม่ใช่ที่สูตร**

```
synergy      (shrink(g,w,0.5) − 0.5)            × 100 × confidence(g)
synergy_adj  (shrink(g,w,0.5) − expected(a,b))  × 100 × confidence(g)
```

### 1.1 `expected_synergy()` คืออะไร

```python
oa = wa / (1 − wa);  ob = wb / (1 − wb)      # odds ของแต่ละตัว
o  = sqrt(oa × ob)                            # รวมแบบ geometric mean
return o / (1 + o)
```

"win rate ที่ควรได้ถ้าฮีโร่สองตัวไม่มีผลต่อกันเลย" — รวมด้วย odds ไม่ใช่คูณตรง ๆ
เพราะทุกเกมมีผู้ชนะเสมอ ค่าจึงถูกบีบให้อยู่รอบ 0.5 โดยโครงสร้าง

docstring ของมันเตือนไว้เองว่า **"ยังไม่สมบูรณ์เพราะไม่ได้หักความแข็งของทีมออก"**

## 2. ⚠️ co-occurrence ≠ synergy — พิสูจน์ด้วยตัวเลขของเราเอง

วัดคู่ที่เล่นด้วยกัน **≥ 20 เกม ทั้งหมด 214 คู่** แล้วเทียบคะแนนสองแบบ

### 6.1 สิ่งที่ **ต่าง** จาก counter และต้องออกแบบใหม่

counter เดิน `Enemy Threat → Mechanism → Capability` ซึ่งมีทิศทางชัด
synergy **ไม่มีทิศทาง** — มันคือ `Capability A + Capability B → Combined Effect`

จาก `synergy.md` §4 (Synergy Types) รูปแบบที่มีคือ

```
Engage + Follow-up        Krizzix รวบ → Zuka/Liliana ทุบ
CC + Burst                Omen/Enzo ล็อก → Billow/Zata เบิร์สต์
Peel + Carry              Thane/Toro ปกป้อง → Capheny/Violet ยิง
Setup + Double Ult        Doria รีเซต → Tachi กดอัลติซ้ำ
Recall/Warp + Split Push  Rouie วาร์ป → Marja ดันเลนข้าง
Gold Boost + Scaling      Teemee เงิน → Capheny ไอเทม
Frontline + Backline      แทงค์ยืนโซน → แผงหลังยิงปลอดภัย
```

ทุกอันมีรูป **`enabler → payoff`** ซึ่งมีทิศทาง แต่คนละแบบกับ counter
ตัว enabler ต้องมาก่อนหรือพร้อมกัน และ payoff ต้องมีอยู่ถึงจะคุ้ม

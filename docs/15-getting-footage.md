# 15 — เอาคลิปแข่งเข้าระบบ

เอกสารนี้ตอบคำถามว่า "จะทำยังไงให้ระบบอ่านไฟล์ mp4 ได้"
และที่สำคัญกว่านั้น **จะทำยังไงให้ตอบคำถาม Phase 0 ที่ค้างอยู่ได้**

---

## 1. แยกสองเรื่องให้ชัดก่อน

| | สถานะ |
|---|---|
| **ระบบอ่าน mp4** | ✅ ทำได้อยู่แล้ว — PyAV + OpenCV ติดตั้งและทดสอบผ่านแล้ว |
| **Claude ดูวิดีโอ** | ❌ ทำไม่ได้ — เห็นได้แค่ภาพนิ่ง |

ทางออกคือ **ให้ระบบตัดเฟรมออกมาเป็นภาพ PNG แล้ว Claude อ่านภาพนั้น**
เมื่ออ่านภาพได้ ก็ตอบคำถาม Phase 0 ที่บล็อกโครงการอยู่ได้ทั้งหมด

```
คลิป mp4  ──rov scan/frames──▶  ภาพ PNG  ──Claude อ่าน──▶  คำตอบ Phase 0
```

---

## 2. หาคลิปจากไหน

ข้อมูลที่ดึงจาก Liquipedia มี **ลิงก์ VOD พร้อมเวลาที่เกมเริ่ม** อยู่แล้ว

```bash
rov vods                       # ทั้งหมด
rov vods --region TH           # เฉพาะลีกไทย
rov vods --team fs             # เฉพาะทีมที่สนใจ
```

ตัวอย่างผลลัพธ์

```
[TH] fs vs godji check · เกม 1 · 12 นาที · ชนะ fs
     https://www.youtube.com/watch?v=xmL6Q2Qa-o0&t=2678s
```

พบ **552 เกมที่มีลิงก์ VOD** และ `&t=` คือวินาทีที่เกมนั้นเริ่มพอดี
จึงไม่ต้องเดาว่าจะตัดช่วงไหน

### เลือกคลิปแบบไหนดี

ตาม [07-roadmap.md](07-roadmap.md) §5 ควรได้ 3 คลิปที่ครอบคลุมกรณียาก

1. เกมที่มี teamfight เยอะ — ทดสอบกรณี icon ทับกัน
2. เกมยาว 20 นาทีขึ้นไป — ช่วงท้ายเกมที่ทุกคนรวมกลุ่ม
3. **คลิปจากคนละรายการ** เช่น RPL หนึ่ง GCS หนึ่ง — ทดสอบว่า layout config ใช้ซ้ำได้ไหม

ความยาวเกมอยู่ในผลลัพธ์ของ `rov vods` แล้ว ใช้เลือกได้เลย

### ดาวน์โหลด

VOD อยู่บน YouTube ดาวน์โหลดด้วยเครื่องมือที่ถนัด
คุณภาพที่ต้องการอย่างน้อย **720p** เพราะ icon บน minimap เล็กมากอยู่แล้ว

ไม่ต้องโหลดทั้ง stream ยาว ๆ ตัดเฉพาะช่วง 20 นาทีของเกมที่สนใจก็พอ
ใช้ `&t=` เป็นจุดเริ่ม

## 3. วางไฟล์แล้วรัน

```bash
# วางไฟล์ไว้ที่
data/videos/rpl2026s_fs_vs_godji_g1.mp4

# 1. ดู metadata ก่อน
rov probe data/videos/rpl2026s_fs_vs_godji_g1.mp4

# 2. สแกนหา minimap
rov scan data/videos/rpl2026s_fs_vs_godji_g1.mp4
```

`rov scan` เขียนภาพสามชุดลง `data/exports/phase0/`

| ไฟล์ | คืออะไร |
|------|---------|
| `frame_*.png` | เฟรมเต็ม พร้อมกรอบผู้สมัครที่เป็น minimap |
| `sdmap.png` | แผนที่ความแปรปรวน — สว่าง = ขยับ, ดำ = นิ่ง |
| `minimap_*.png` | บริเวณที่สงสัย ขยาย 4 เท่า |

**หลักการ:** main view กล้องเคลื่อนตลอด ความแปรปรวนสูง
minimap พื้นหลังนิ่ง ความแปรปรวนต่ำ จึงหาเจอจาก `sdmap.png`

⚠️ ตัวเลขที่ `rov scan` เสนอเป็น **ข้อเสนอ ไม่ใช่คำตอบ**
ทดสอบกับคลิปสังเคราะห์แล้วมันเลือกผิด เพราะคลิปนั้นมีบริเวณนิ่งหลายจุด
บนคลิปแข่งจริงความต่างจะชัดกว่ามาก แต่**ยังต้องยืนยันด้วยตาเสมอ**

## 4. ตัดเฟรมเจาะจง

```bash
# กระจายทั้งคลิป
rov frames data/videos/x.mp4 --n 10

# เจาะเวลาที่ต้องการ (วินาที)
rov frames data/videos/x.mp4 --at 300,610,900

# ตัดเฉพาะ minimap แล้วขยาย 4 เท่า
rov frames data/videos/x.mp4 --at 300,610 --crop 18,16,186,186 --zoom 4
```

`--crop x,y,w,h` กับ `--zoom` คือคู่ที่สำคัญที่สุด
เพราะ icon บน minimap เล็กราว 18 pixel ถ้าไม่ขยายก็ดูไม่ออก

## 5. คำถาม Phase 0 ที่จะตอบได้เมื่อมีคลิป

จาก [01-assessment.md](01-assessment.md) §4 — ทั้งหมดตอบได้จากการดูภาพ

| # | คำถาม | ดูจากภาพไหน |
|---|-------|-------------|
| 1 | **minimap มี fog of war หรือไม่** 🔴 | crop minimap ตอนสองทีมแยกกัน แล้วนับ icon ได้ 10 หรือน้อยกว่า |
| 2 | สี icon = ฝ่าย หรือ มิตร/ศัตรู | crop minimap เทียบกับ HUD |
| 3 | minimap ROI พิกัดเท่าไร | `sdmap.png` + `frame_*.png` |
| 4 | icon เส้นผ่านศูนย์กลางกี่ pixel | `minimap_*.png` ที่ขยายแล้ว |
| 5 | minimap เป็นจัตุรัสตรงหรือถูกบิด | `minimap_*.png` |
| 6 | นาฬิกาเกมอยู่ตรงไหน | `frame_*.png` |
| 7 | HUD บอกสถานะตายอย่างไร | crop HUD ตอนมีคนตาย |
| 8 | มี replay บ่อยแค่ไหน | เฟรมกระจายทั้งคลิป |
| 9 | teamfight icon ทับกันแค่ไหน | crop minimap ตอน fight |
| 10 | ping กับ marker หน้าตาอย่างไร | crop minimap หลายเฟรม |
| 11 | mark ของ Dragon/Slayer อยู่ตรงไหน สีอะไร | `minimap_*.png` |
| 12 | เวลาเกิด objective ตรงกับตารางไหม | เฟรมที่นาที 2, 8, 10 |

**ข้อ 1 สำคัญที่สุด** เพราะมันตัดสินว่าจะออกแบบ tracking แบบไหน
และเป็นคำถามที่ค้นเว็บแล้วไม่มีคำตอบ (docs/08 §5)

## 6. หลังตอบครบแล้วจะเกิดอะไร

```
ตอบคำถาม 12 ข้อ
      ↓
เขียน configs/layouts/<id>.yaml
      ↓
rov layout-check <layout> --video <clip>     ← วาดกรอบทับเฟรมยืนยัน
      ↓
ผ่าน Phase 0
      ↓
เทียบ threshold ของ detector กับคลิปจริง     ← Milestone 1 ตัวจริง
      ↓
ยืนยันผังโซนกับ minimap จริง (configs/zones)
```

ตอนนี้ detector ผ่านเกณฑ์แล้วบนชุดสังเคราะห์เท่านั้น
ค่าพารามิเตอร์ที่จูนไว้ **ห้ามเชื่อ** จนกว่าจะวัดกับคลิปจริง (docs/09 §3)

---

## 7. สรุปสั้นที่สุด

```bash
rov vods --region TH              # หาคลิป
# ดาวน์โหลดแล้ววางที่ data/videos/
rov scan data/videos/<ไฟล์>.mp4    # สแกน
# แล้วบอก Claude ให้อ่านภาพใน data/exports/phase0/
```

ขอแค่ **คลิปเดียว** ก็ปลดล็อกงานที่ค้างอยู่ได้เกือบทั้งหมด

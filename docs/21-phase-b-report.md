(สี่ตัวหลักต้องมีเสมอ · ทุกตัวที่มีต้องอธิบายตัวเองได้)
และเพิ่มเทสต์ใหม่กันไม่ให้มี component ที่ไม่มีน้ำหนักรองรับ —
`base` ใช้ `.get(k, 0)` จึงไม่ระเบิดถ้าลืมใส่ แต่จะกลายเป็น factor ที่ไร้ผลเงียบ ๆ

## 8. Unresolved issues

1. **`composition` เปิดน้ำหนักแล้วผลแย่ลงเล็กน้อย** (top-1 8→7 ที่น้ำหนัก 1.5)
   ยังไม่รู้ว่าเป็นเพราะสูตร `_composition_fit` ยังไม่ดี หรือเพราะ attribute
   ที่ `assistant` กรอกยังไม่แม่นพอ หรือเพราะ noise — **ต้องแยกสามอย่างนี้ก่อนตัดสิน**
2. **`lane_counter` ครอบคลุมแค่ 3.3%** เพราะคู่ที่ประกบกันในเลนเดียวกันมีตัวอย่างน้อย
   `MIN_LANE_PAIR = 3` อาจต่ำเกินไปหรือสูงเกินไป ยังไม่ได้ทดสอบ
3. **เกณฑ์ ±0.12 ของ win condition ยังไม่มีที่มา** กำกับ `verified: False` ไว้แล้ว
4. **top-1 4.8% ตีความยาก** ต้องมี baseline เทียบ (เช่น "เลือกตัว presence สูงสุด")
   ถึงจะรู้ว่า 4.8% ดีหรือแย่ — ยังไม่ได้ทำ
5. **eval set มีแค่ 167 scored turns** เล็กเกินกว่าจะแยก noise ออกจาก signal
   ต้องขยายและทำ cross-validation ใน PHASE I
6. **`derive_traits()` เกณฑ์ยังไม่ได้ตรวจ** (`mobility < 40` = immobile ฯลฯ)
   เป็นค่าที่ตั้งจากสามัญสำนึก ยังไม่มีหลักฐาน — แต่ยังไม่กระทบอะไรเพราะ
   `trait_counter()` คืน `None` อยู่แล้ว

## 9. พร้อมสำหรับ PHASE M หรือยัง

**พร้อม** โดยมีเงื่อนไข

### ที่พร้อมแล้ว

- ✅ มี regression snapshot ที่พิสูจน์ได้ว่าการเปลี่ยนแปลงกระทบอะไรบ้าง
- ✅ มี benchmark พร้อม leakage guard — วัดก่อน/หลังได้ทุกครั้ง
- ✅ โครง factor รองรับการเพิ่มโดยไม่กระทบของเดิม (`w_all.get(k, 0.0)`)
- ✅ `partial_dimensions()` พร้อมให้ counter/synergy engine เรียกใช้
- ✅ `derive_traits()` พร้อมรับ tag จาก kit
- ✅ ชุดเทสต์ที่เสถียรจริง (แก้ flaky test ที่มีมาก่อนแล้ว)
- ✅ `counter_score` เหลือที่เดียวฝั่ง Python — เพิ่ม context ใหม่ได้โดยไม่ซ้ำสูตร

### ที่ต้องทำก่อนเริ่ม PHASE M

1. **ขยาย eval set และหา baseline เทียบ** ไม่งั้น PHASE M จะอ้างว่าดีขึ้นไม่ได้
   เหมือนที่ PHASE B อ้างไม่ได้ตอนนี้
2. **ตัดสินใจเรื่อง `coach_source`** ใน [docs/20 §4](20-draft-intelligence-spec.md)
   ก่อนนำเข้า kit ไม่งั้นจะได้ provenance ที่แยกไม่ออกจาก `assistant`
3. **เติม hero attribute กลุ่ม 2 (16 ตัว)** จาก [docs/18](18-hero-data-coverage.md)
   `composition` ครอบคลุม 77% แล้วก็จริง แต่นั่นวัดบน top-5 candidate
   ซึ่งเอนไปทางตัวยอดนิยม — ทีมจริงยังมีตัวที่ยังไม่กรอกปนอยู่บ่อย
